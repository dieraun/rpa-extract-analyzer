# 合规、授权与免责声明

## 1. 用途声明

`rpa-loader-analyzer` 是本地、只读的**技术学习与兼容性研究工具**，用于：

- 学习 Ren'Py loader 的静态分析方法和 RPA 归档结构；
- 对**拥有合法授权**的游戏文件做数据备份、资源清点和格式研究；
- 在获得授权的范围内做本地化、兼容性测试或教学演示。

本工具**不是**破解工具，不提供游戏本体、密钥库、付费内容或规避授权的服务。

## 2. 使用者的前置义务

在运行任何命令前，使用者必须确认：

1. 对目标游戏目录、`loader.pyo` 和全部 RPA 文件拥有合法访问与处理授权；
2. 处理行为不违反游戏最终用户许可协议（EULA）、服务条款、劳动合同或保密协议；
3. 处理行为符合所在地法律，包括但不限于著作权法、计算机信息系统安全法规、
   数字版权管理（DRM）相关法规；
4. 不将工具用于绕过付费墙、在线验证、反作弊、访问控制或其他技术保护措施；
5. 不传播、公开发布或商业利用从游戏中提取的受版权保护资源。

**如果无法确认授权，请不要使用本工具。**

## 3. 明确禁止的用途

- 破解、盗版、私服运营或协助上述行为；
- 绕过 DRM、联网验证、反作弊或访问控制；
- 提取并传播未授权的美术、音乐、剧情、配音等版权内容；
- 对在线服务、他人设备或第三方系统进行未授权测试；
- 将本工具改造成恶意软件、混淆器、打包器或攻击工具；
- 上传游戏二进制、源码、密钥或导出资源到网络服务。

## 4. 数据处理

- 工具全程本地运行，不包含上传逻辑。
- 分析日志和 JSON 报告可能包含本地文件路径、文件名和 XOR 密钥。这些数据仍可能敏感，
  请妥善保管，不要随意公开。
- 导出资源写入用户指定的独立输出目录；工具拒绝写入游戏根目录。
- 原始游戏文件以只读方式打开，工具不会修改、覆盖或删除它们。
- 使用者应自行做好备份和访问控制。

## 5. 第三方组件

- **uncompyle6 / xdis**：用于字节码反编译、反汇编和版本识别，遵循其各自许可证。
- **FFmpeg / ffprobe**：可选外部程序，仅在用户显式执行 `convert` 时调用；遵循其各自
  许可证。本项目不下载、不打包 FFmpeg。
- **PyInstaller**：仅在构建 Windows EXE 时使用，遵循其许可证。
- Python 标准库：`ast`、`pickletools`、`zlib`、`subprocess`、`tkinter` 等。

使用者需自行确认第三方组件的许可证和分发要求。
